# 초기 리뷰로 상품의 이후 저평점 위험 예측

## 목적 및 배경

온라인 상품의 초기 평균 별점만으로는 이후 소비자 평가를 충분히 파악하기 어렵다. 본 연구는 상품의 초기 관측 리뷰 10개를 활용하여 후속 20개 리뷰의 저평점 비율을 예측하고, 리뷰 내용이 별점 외에 추가적인 예측 정보를 제공하는지 검증한다. 이를 통해 데이터 분석과 자연어 처리, 머신러닝 모델의 구현 및 평가 역량을 기르고자 한다.

---

## 연구개발 내용

Amazon Reviews 2023의 All_Beauty 리뷰 701,528건 중 초기 10개와 후속 20개 리뷰를 확보할 수 있는 리뷰가 30개 이상인 상품 3,692개를 분석 대상으로 활용한다.

상품별 리뷰를 작성 시각순으로 정렬하고, 후속 20개 리뷰 중 1~2점 리뷰의 비율을 예측 목표로 설정한다.

비교 모델은 다음과 같다.

- 초기 평균 별점만 사용하는 기준 모델
- 별점 분포, 리뷰 길이, 구매 인증 비율 등을 추가한 정형 특성 기반 모델
- 리뷰 제목 및 본문의 TF-IDF 텍스트 특성을 결합한 모델

동일 상품이 학습 데이터와 평가 데이터에 동시에 포함되지 않도록 분리하며, 텍스트 어휘 및 전처리 기준은 학습 데이터에서만 산출한다.

모델 성능은 MAE와 RMSE를 활용하여 평가하며, 시간순 평가에서는 학습에 사용하는 후속 리뷰가 평가 시점보다 앞서도록 구성한다.

또한 초기 별점이 유사하지만 이후 저평점 비율이 다른 상품을 비교하여 관련 표현과 주제, 예측 실패 사례를 분석한다.

## 결과 및 기대효과

초기 별점과 리뷰 내용을 활용한 후속 저평점 비율 예측 모델을 구축하고, 텍스트 정보 추가에 따른 성능 차이를 정량적으로 제시한다.

또한 소비자의 불만과 관련된 표현을 분석하여 초기 리뷰의 활용 가능성을 탐색하고, 데이터 누수 방지와 모델 해석 역량을 확보한다.

분석 결과는 해외 뷰티 상품 중 충분한 후속 리뷰가 존재하는 상품에 한정되며, 실제 불량 여부나 국내 상품 전반으로의 일반화에는 한계가 있음을 명시한다.

## 폴더 구조

```text
review-forecast/
├── data/                              # 데이터 및 출처 설명
│   └── All_Beauty.jsonl.gz            # 실제 리뷰 파일 (압축본, Git 포함)
├── scripts/
│   ├── week1_all_beauty_inspection.py  # 1주차 데이터 확인 및 기초 통계
│   └── Amazon-Reviews-2023.py         # 가져온 Hugging Face 데이터 로딩 코드
├── reports/
│   ├── week1.md                       # 1주차 활동 및 주요 결과
│   └── week1_output.txt               # 스크립트 실행 결과
├── environment.yml                    # Conda 환경 설정
├── requirements.txt                   # Python 라이브러리 목록
└── .gitignore                         # 비압축 원본·임시 파일 제외 설정
```

## 실행 방법

레포 폴더에서 실행한다.

```bash
python scripts/week1_all_beauty_inspection.py
```

리뷰 데이터는 `data/All_Beauty.jsonl.gz`에 포함되어 있으며, 압축을 풀지 않고 사용한다.

데이터 출처: [Amazon Reviews 2023](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023)

## 협업 안내

- 코드는 `scripts/`, 활동 기록과 결과는 `reports/`에 저장한다.
- 데이터는 압축 JSONL을 공유하며, 비압축 원본과 개인 가상환경은 Git에서 제외한다.
- 라이브러리를 추가하면 `environment.yml`과 `requirements.txt`에도 반영한다.
