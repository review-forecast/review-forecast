# 3주차 활동 보고서

## 활동 주제

회귀 분석 학습, 초기 평균 별점 기반 기준 모델 및 정형 특성 확장 모델 구현

## 활동 내용

금주에는 회귀 분석의 개념과 평가 방법을 학습하고, 2주차에 구성한 상품별 분석 데이터를 활용하여 초기 평균 별점 기반 기준 모델과 정형 특성 확장 모델을 구현하였다. 예측 목표는 각 상품의 후속 20개 리뷰 중 1~2점 리뷰의 비율로 설정하였다.

회귀 분석 학습에서는 설명변수와 연속형 목표변수 사이의 관계를 이용해 예측하는 방법을 정리하였다. 또한 평균 절대 오차인 MAE와 큰 오차에 더 민감한 RMSE의 차이를 복습하였고, 모델이 평균값만 예측하는 것보다 얼마나 더 잘 설명하는지를 확인하기 위해 R²도 함께 산출하였다.

기준 모델은 처음 10개 리뷰의 평균 별점 하나만을 입력으로 사용하는 선형회귀로 구현하였다. 정형 특성 확장 모델은 초기 평균 별점에 별점 표준편차, 초기 저평점 비율, 1~5점별 비율, 평균 본문·제목 길이, 본문 존재 비율, 구매 인증 비율을 추가하였다. 별점 관련 특성 사이의 중복된 정보와 다중공선성의 영향을 줄이기 위해 특성을 표준화한 Ridge 회귀를 적용하였으며, 규제 강도는 학습 데이터 내 5겹 교차 검증으로 선택하였다.

전체 3,643개 상품을 고정된 난수 시드 42로 나누어 2,914개를 학습에, 729개를 평가에 사용하였다. 하나의 행이 하나의 상품을 나타내므로 학습과 평가 집합 간 상품 중복은 발생하지 않도록 구성하였다. 이번 분할은 3주차 모델 구현을 비교하기 위한 임시 랜덤 홀드아웃이며, 연구 계획서의 정식 시간순 평가는 5주차에 수행할 예정이다.

평가 데이터에서 기준 모델의 MAE는 **0.0977**, RMSE는 **0.1264**, R²는 **0.3952**로 나타났으며, 정형 특성 확장 모델의 MAE는 **0.0970**, RMSE는 **0.1258**, R²는 **0.4013**으로 나타났다. 확장 모델의 MAE는 기준 모델보다 약 **0.74%** 낮아졌다. 이를 통해 초기 평균 별점 외의 정형 특성이 후속 저평점 비율 예측에 추가적인 정보를 제공할 가능성은 확인하였으나, 개선 폭은 크지 않았다. 따라서 현재 결과만으로 정형 특성의 효과를 강하게 결론내리기보다는, 4주차 텍스트 특성 추가와 5주차 시간순 평가에서 개선이 재현되는지 확인할 필요가 있다.

모델에 사용한 설명변수는 모두 초기 10개 리뷰에서만 계산하였고, 후속 20개 리뷰의 정보는 예측 목표 산출에만 사용하였다. 또한 학습·평가 상품 식별자의 교집합이 비어 있는지, 타깃값과 예측값이 유효한 비율 범위에 있는지를 자동으로 검사하였다. 이번 활동을 통해 재현 가능한 별점·정형 특성 기반 회귀 모델을 구현하고, 다음 주 텍스트 특성 결합 모델과 비교할 기준을 마련하였다.

## 코딩 / 오픈소스 SW 활동

Python과 Pandas를 활용하여 2주차에 생성한 상품별 특성 데이터를 불러오고, 모델링에 필요한 열의 결측치와 범위, 상품 식별자의 유일성을 점검하였다. Scikit-learn의 `train_test_split`, `LinearRegression`, `StandardScaler`, `RidgeCV`를 이용하여 고정된 난수 기반의 재현 가능한 학습 및 평가 절차를 구현하였다.

초기 평균 별점만 사용한 선형회귀 모델과 12개 정형 특성을 사용한 Ridge 회귀 모델을 학습하고, MAE·RMSE·R²를 계산하여 CSV로 저장하였다. 상품별 예측값과 절대 오차, 학습·평가 분할 정보, 표준화된 모델 계수도 함께 저장하여 후속 분석에서 재사용할 수 있도록 하였다.

Matplotlib을 활용하여 두 모델의 MAE와 RMSE를 비교하고, 실제 후속 저평점 비율과 예측값의 관계를 시각화하였다. 분석 코드와 실행 출력, 성능표, 상품별 예측 결과, 특성 계수, 시각화 파일을 저장소의 기존 폴더 구조에 맞춰 정리하였다.
