# 4주차 활동 보고서

## 활동 주제

텍스트 전처리와 TF-IDF 학습, 리뷰 제목·본문을 활용한 결합 모델 구현

## 활동 내용

금주에는 초기 10개 리뷰의 제목과 본문을 정제하고 TF-IDF로 수치화한 뒤, 3주차의 정형 특성과 결합한 회귀 모델을 구현하였다. 이를 통해 리뷰 텍스트가 초기 별점 및 정형 특성 외에 후속 20개 리뷰의 저평점 비율을 예측하는 데 추가적인 정보를 제공하는지 확인하였다. 3주차 모델과 직접 비교할 수 있도록 동일한 상품 분할(학습 2,914개 / 평가 729개)을 그대로 사용하였다.

TF-IDF 학습에서는 단어 빈도(TF)와 역문서 빈도(IDF)를 곱해 여러 문서에 흔히 등장하는 단어의 가중치는 낮추고, 특정 문서를 구별하는 단어의 가중치는 높이는 원리를 정리하였다. Scikit-learn의 기본 설정인 평활 IDF와 L2 정규화, 빈도를 로그 척도로 줄이는 `sublinear_tf`, 연속된 두 단어를 하나의 특성으로 보는 bigram, 너무 드물거나 흔한 단어를 거르는 `min_df`·`max_df`의 역할을 학습하였다. 예시 문장 3개로 TF-IDF 행렬을 직접 계산한 결과, "great"처럼 한 문서에서 반복된 단어와 "not work", "broke"처럼 한 문서에만 등장한 표현이 높은 가중치를 받는 것을 확인하였다. 또한 텍스트 특성의 수가 학습 상품 수보다 훨씬 많아지므로, 과적합을 막기 위해 규제가 있는 Ridge 회귀를 사용하였다.

텍스트 전처리에서는 먼저 초기 리뷰 본문의 약 9.6%에 포함된 `<br />` 태그와 `&#34;` 같은 HTML 엔티티를 제거하고, 모든 문자를 소문자로 변환하였다. URL과 숫자는 각각 하나의 토큰으로 치환하였다. 불만 표현에서 부정어가 중요하므로 "doesn't", "won't" 같은 축약형은 "not"이 분리되도록 처리하였다. Scikit-learn의 기본 영어 불용어 목록에는 "not", "no"가 포함되어 있어 사용하지 않았고, 대신 학습 상품의 90% 이상에 등장하는 단어를 `max_df`로 제외하였다. 이후 상품마다 초기 10개 리뷰의 제목과 본문을 각각 이어 붙여 제목 문서와 본문 문서를 구성하였다. 상품별 본문 문서는 평균 약 426단어, 제목 문서는 약 42단어였다.

모델은 텍스트만 사용하는 모델 A, 정형 특성에 제목을 더한 모델 B, 정형 특성에 본문을 더한 모델 C, 정형 특성·제목·본문을 모두 결합한 모델 D로 구성하였다. 제목과 본문은 길이와 표현 방식이 달라 별도의 TF-IDF로 변환하였고, 표준화한 정형 특성 12개와 수평으로 결합하여 Ridge 회귀에 입력하였다. 규제 강도, n-gram 범위, 최소 문서 빈도, 정형 특성 대비 텍스트 블록의 가중치는 학습 상품 내 5겹 교차 검증으로 선택하였다. TF-IDF의 어휘와 IDF는 교차 검증의 각 학습 fold와 최종 학습 상품에서만 산출하여, 평가 상품의 텍스트 정보가 학습에 들어가지 않도록 하였다. 최종 모델 D는 학습 상품에서 제목 1,021개, 본문 4,378개의 어휘를 사용하였다.

평가 데이터에서 결합 모델 D의 MAE는 **0.0937**, RMSE는 **0.1226**, R²는 **0.4308**로 여섯 모델 중 가장 낮은 오차를 보였다. 이는 3주차 기준 모델(MAE 0.0977) 대비 **4.12%**, 정형 특성 확장 모델(MAE 0.0970) 대비 **3.41%** 낮은 값이다. 제목만 추가한 모델 B와 본문만 추가한 모델 C도 정형 특성 확장 모델보다 MAE가 각각 2.13%, 2.26% 낮아, 제목과 본문이 각각 추가 정보를 제공하며 둘을 함께 사용할 때 개선 폭이 가장 컸다. 반면 텍스트만 사용한 모델 A의 MAE는 0.0973으로 기준 모델과 비슷한 수준에 그쳐, 텍스트는 별점을 대체하기보다 보완하는 정보로 해석된다.

3주차에서 정형 특성의 개선 폭이 0.74%로 작았던 점을 고려하여, 평가 상품 729개를 1,000회 복원추출하는 대응 부트스트랩으로 개선의 안정성을 확인하였다. 정형 특성 확장 모델 대비 모델 D의 MAE 감소량은 0.0033이었으며, 95% 구간은 [0.0015, 0.0052]로 0을 포함하지 않았다. 모델 B와 C의 구간도 0보다 컸으나, 모델 A의 구간은 0을 포함하였다. 다만 이 구간은 하나의 랜덤 분할에서 평가 상품 구성에 따른 변동만 반영하므로, 5주차 시간순 평가에서 개선이 재현되는지 다시 확인할 필요가 있다.

또한 초기 리뷰 제목의 약 13.2%가 "Five Stars"처럼 별점을 그대로 적은 자동 생성 문구였다. 텍스트 효과가 이 문구 때문에 생긴 것은 아닌지 확인하기 위해 해당 제목을 지우고 모델 D를 같은 설정으로 다시 학습하였다. 그 결과 MAE는 0.0936으로 거의 변하지 않아, 개선이 별점 문구의 중복 정보가 아니라 리뷰 내용에서 비롯된 것으로 판단하였다.

텍스트 모델 A의 계수를 살펴보면, 후속 저평점 비율을 높이는 방향으로는 제목의 "not buy", "cheap", "waste", "not worth", "horrible"과 본문의 "not work", "waste" 등이 상위에 나타났다. 반대로 낮추는 방향으로는 제목의 "great", "excellent", "best", "love", "good quality" 등이 나타났다. 축약형에서 분리한 "not"이 포함된 표현이 상위에 다수 등장하여, 부정어를 보존한 전처리가 의미 있는 신호를 남긴 것으로 보인다. 다만 "do", "to apply"처럼 단독으로는 해석이 어려운 표현도 있어, 표현과 오차 사례에 대한 분석은 5주차에 이어서 진행할 예정이다.

이번 활동을 통해 리뷰 텍스트의 전처리와 TF-IDF 변환 과정을 구현하고, 텍스트 특성이 정형 특성과 결합될 때 후속 저평점 비율 예측을 개선할 수 있음을 확인하였다. 다음 주에는 시간순 평가를 적용하여 모델 성능을 다시 비교하고, 주요 표현과 예측 오차 사례를 분석할 예정이다.

## 코딩 / 오픈소스 SW 활동

Python과 Pandas를 활용하여 2주차에 생성한 리뷰 구간 데이터에서 초기 구간의 리뷰만 불러오고, 상품별 초기 리뷰가 10개인지 확인하였다. 표준 라이브러리의 `html`과 `re`로 HTML 엔티티와 태그 제거, 부정 축약형 분리, URL·숫자 치환 등의 텍스트 정제 함수를 구현하였으며, 별도의 자연어 처리 라이브러리는 추가하지 않았다.

Scikit-learn의 `TfidfVectorizer`, `StandardScaler`, `ColumnTransformer`, `Ridge`, `Pipeline`을 이용하여 제목·본문 TF-IDF와 정형 특성을 결합한 모델을 구성하였다. 텍스트 블록 가중치는 변환 결과에 상수를 곱하는 것과 같으므로, 각 fold에서 TF-IDF를 한 번만 학습하고 가중치와 규제 강도만 바꾸어 평가하도록 교차 검증을 구현하였으며, `joblib`으로 fold 단위 계산을 병렬화하였다. 3주차 스크립트의 분할·평가·기준 모델 함수를 그대로 불러와 사용하고, 3주차에 기록된 성능이 동일하게 재현되는지 자동으로 검사하였다.

모델별 성능, 상품별 예측값과 절대 오차, 교차 검증 결과, 부트스트랩 구간, 상위 텍스트 특성을 CSV로 저장하였다. Matplotlib으로 모델별 MAE·RMSE, 정형 특성 확장 모델 대비 MAE 감소량의 95% 구간, 결합 모델의 관측값-예측값 산점도를 3주차와 같은 형식으로 시각화하였다. 분석 코드와 실행 출력, 결과 파일을 저장소의 기존 폴더 구조에 맞춰 정리하였다.
