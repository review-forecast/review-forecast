# 1주차 활동 기록

## 활동 주제

역할 분담, Amazon 리뷰 데이터 구조와 기초 통계 학습

## 활동 계획

- 연구 목표 및 팀원별 역할 정리
- 주요 필드의 의미 확인: `parent_asin`, `rating`, `title`, `text`, `timestamp`, `verified_purchase`, `helpful_vote`
- 실제 데이터 파일의 구조와 별점 기초 통계 확인
- 상품별 리뷰 수 확인 및 작성 시각순 정렬

## 실행 기록

Conda `review-forecast` 환경에서 원본 리뷰 파일로 실행을 완료했습니다. 전체 출력은 `week1_output.txt`에 저장했습니다.

- 실행 날짜: 2026-10-07
- 사용한 파일 및 형식: `data/All_Beauty.jsonl` (공식 Hugging Face 원본 리뷰)
- 전체 리뷰 수 / 열 수: 701,528건 / 10개
- 상품 수: 112,565개
- 평균 별점 / 표준편차: 3.960245 / 1.494452
- 전체 리뷰의 저평점(1~2점) 비율: 20.6854%
- 리뷰 30개 이상인 상품 수: 3,692개 (정제 전 후보)
- 발견한 결측치 및 자료형 문제: 주요 7개 필드의 결측치, 유효하지 않은 별점 및 시각 변환 실패 모두 0건. 기존 Parquet는 상품 메타데이터(112,590행)여서 별도 원본 리뷰 파일로 분석함.
