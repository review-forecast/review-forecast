# 2주차 활동 보고서

## 활동 주제

결측·중복 데이터 점검, 상품별 초기·후속 리뷰 구성 및 탐색적 분석

## 활동 내용

금주에는 Amazon Reviews 2023의 All_Beauty 리뷰 데이터를 대상으로 결측치와 중복 데이터를 점검하고, 상품별 초기 10개 리뷰와 후속 20개 리뷰를 구성하였다. 또한 초기 리뷰의 별점 및 정형 특성과 후속 저평점 비율의 관계를 탐색하여 다음 주 모델 구현에 활용할 분석 데이터를 준비하였다.

데이터 품질 점검에서는 상품 식별자, 별점, 작성 시각, 리뷰 제목과 본문, 구매 인증 여부 등 주요 필드의 결측치와 값의 유효성을 확인하였다. 주요 필드의 결측치와 유효하지 않은 별점, 작성 시각 변환 실패는 모두 0건이었다. 다만 리뷰 본문이 빈 문자열 또는 공백으로 구성된 경우가 720건 확인되었다. 해당 리뷰는 별점과 작성 시각을 활용할 수 있으므로 삭제하지 않고 유지하였다.

중복 점검에서는 원본의 모든 필드가 동일한 리뷰가 반복된 경우를 완전 중복으로 정의하고, 처음 등장한 한 건만 남겼다. 전체 701,528건 중 완전 중복 7,275건을 제거하여 정제 후 리뷰는 694,253건으로 구성되었다. 같은 상품에 동일 작성자가 여러 리뷰를 남긴 경우에는 서로 다른 리뷰일 수 있으므로 일괄 삭제하지 않았다. 정제 전 리뷰 30개 이상 상품은 3,692개였으며, 중복 제거 후 49개 상품이 30개 미만으로 줄어 최종 분석 대상은 3,643개로 확인되었다.

상품별 리뷰 구성에서는 `parent_asin`을 기준으로 상품을 구분하고, `timestamp`를 이용하여 작성 시각순으로 정렬하였다. 각 상품의 첫 10개 리뷰를 초기 관측 리뷰로, 바로 다음 20개 리뷰를 후속 리뷰로 구성하였다. 후속 20개 중 1~2점 리뷰의 비율을 예측 목표로 설정하였으며, 초기 리뷰 36,430건과 후속 리뷰 72,860건을 확보하였다. 동일 시각의 리뷰는 원본 행 순서로 정렬하였고, 초기·후속 구간의 경계 시각이 같은 상품 1개는 향후 시간순 평가에서 확인할 수 있도록 별도로 표시하였다.

탐색적 분석에서는 초기 평균 별점, 별점 표준편차, 저평점 비율, 리뷰 본문 길이, 구매 인증 비율 등을 계산하고 후속 저평점 비율과의 관계를 확인하였다. 분석 대상 상품의 초기 평균 별점은 평균 약 4.22점이었으며, 후속 저평점 비율은 평균 약 19.03%, 중앙값 15%로 나타났다. 초기 평균 별점과 후속 저평점 비율의 상관계수는 약 -0.660으로, 초기 별점이 높은 상품일수록 이후 저평점 비율이 낮은 경향을 확인하였다. 초기 저평점 비율과 별점 표준편차의 상관계수는 각각 약 0.637과 0.452로 나타나, 초기 별점의 분포도 함께 살펴볼 필요가 있음을 확인하였다.

또한 초기 평균 별점이 같지만 후속 평가가 다른 상품을 비교하였다. 초기 평균이 3.6점으로 동일한 두 상품에서도 후속 저평점 비율이 각각 0%와 90%로 나타났다. 이를 통해 초기 평균 별점만으로는 상품별 후속 평가의 차이를 충분히 설명하기 어려울 수 있음을 확인하였다. 다만 해당 사례는 차이가 큰 상품을 선택한 탐색 결과이며, 리뷰 텍스트가 추가적인 예측 정보를 제공하는지는 이후 모델 성능 비교를 통해 검증할 예정이다.

이번 활동을 통해 데이터 정제 기준을 정리하고 상품별 초기·후속 리뷰와 예측 목표를 구성하였다. 또한 주요 특성의 분포와 후속 저평점 비율의 관계를 확인하여 모델 구현을 위한 기반을 마련하였다. 다음 주에는 회귀 분석을 학습하고, 초기 평균 별점 기반 기준 모델과 정형 특성을 추가한 모델을 구현할 예정이다.

## 코딩 / 오픈소스 SW 활동

Python과 Pandas를 활용하여 압축 JSONL 형식의 원본 리뷰 데이터를 불러오고, 주요 필드의 결측치, 빈 문자열, 별점 범위 및 작성 시각 변환 여부를 점검하였다. 원본의 전체 필드를 기준으로 완전 중복 리뷰를 판별하고 제거하였으며, 정제 전후 리뷰 수와 상품별 리뷰 수의 변화를 집계하였다.

또한 상품 식별자와 작성 시각을 기준으로 리뷰를 정렬하고, 상품별 초기 10개와 후속 20개 리뷰를 구성하였다. 초기 리뷰에서 별점별 비율, 평균 별점, 별점 표준편차, 제목과 본문 길이, 구매 인증 비율 등을 계산하였으며, 후속 리뷰에서 1~2점 리뷰 수와 비율을 산출하였다. 상품별 구간의 리뷰 수, 시간순 정렬 및 목표값 계산의 정합성도 확인하였다.

Matplotlib을 활용하여 후속 저평점 비율의 분포, 초기 평균 별점과 후속 저평점 비율의 산점도, 초기 별점 구간별 후속 저평점 비율의 분포를 시각화하였다. 분석 코드와 실행 출력, 상품별 분석 데이터 및 비교 사례는 저장소의 기존 폴더 구조에 맞춰 로컬 파일로 정리하였다.
